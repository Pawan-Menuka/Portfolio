# Local scene font

`Inter.ttf` is an unchanged copy of Inter's upright variable font from Google Fonts:

https://raw.githubusercontent.com/google/fonts/main/ofl/inter/Inter%5Bopsz,wght%5D.ttf

Retrieved 2026-09-08. Copyright 2020 The Inter Project Authors. Distributed under the SIL Open Font License 1.1; the full notice and license are in `OFL.txt` alongside the font.

Size: 876,576 bytes.
SHA256: `29160a80ff49ddcab2c97711247e08b1fab27a484a329ce8b813d820dc559031`.

Only the lazy desktop scene requests this font. A later production optimization can create a licensed Latin subset; the current file preserves the upstream binary unchanged.

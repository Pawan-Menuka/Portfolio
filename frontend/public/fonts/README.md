# Local scene font

`Inter.ttf` is a Basic Latin subset of Inter's upright variable font from Google Fonts:

https://raw.githubusercontent.com/google/fonts/main/ofl/inter/Inter%5Bopsz,wght%5D.ttf

The upstream font was retrieved 2026-09-08. The subset was generated with FontTools 4.65.0 using Unicode range `U+0020-007E`; variation and layout tables were retained. Copyright 2020 The Inter Project Authors. Distributed under the SIL Open Font License 1.1; the full notice and license are in `OFL.txt` alongside the font.

Upstream size: 876,576 bytes.
Upstream SHA256: `29160a80ff49ddcab2c97711247e08b1fab27a484a329ce8b813d820dc559031`.

Subset size: 168,344 bytes.
Subset SHA256: `3f428aa071560986b55d06d09246fa0b8207fe247b53f88c341baf1e38100b16`.

Only the lazy 3D scene requests this font. The subset contains every printable Basic Latin character, which covers the current labels and future English label edits without shipping the unused global glyph inventory.
